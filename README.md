One funny toaster error line (105 characters), written by a tiny Node program to `entry.txt`:

> Toast ejected successfully. Toast status: deceased. Please hold a small funeral before reinserting bread.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR`). Node 22+, standard library only, no dependencies.
